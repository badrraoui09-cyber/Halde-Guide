# Halde Guide – Inhalte bearbeiten

## Anmeldung

1. Im Browser `https://DEINE-DOMAIN.de/admin/` öffnen.
2. Mit der eingeladenen E-Mail-Adresse und dem Passwort anmelden.

## Texte der Website ändern

1. **Website – alle Texte** öffnen.
2. **Texte bearbeiten** auswählen.
3. Den gesuchten bisherigen Text in der Liste aufklappen.
4. Nur das Feld **Text auf der Website** ändern.
5. Oben auf **Veröffentlichen** klicken.
6. Kurz warten und die Website neu laden.

Die internen Nummern und der bisherige Originaltext werden vom System verwaltet und sollen nicht verändert werden.

## 12-Wochen-Plan ändern

1. **AP1 – 12-Wochen-Plan** öffnen.
2. **Wochenplan** auswählen.
3. Eine Woche aufklappen.
4. Titel, Praxis-Aufgaben, Theorie-Themen oder Checkliste ändern.
5. Mit **Veröffentlichen** speichern.

## Bilder hochladen

Bilder können in der Medienverwaltung hochgeladen werden. Sie landen automatisch im Ordner `images/uploads`. Ein Bild erscheint erst auf der Website, wenn ein entsprechendes Bildfeld im CMS mit dem gewünschten Bereich verbunden wurde.

## Einmalige Netlify-Einrichtung

1. Das Projekt-Repository mit Netlify verbinden.
2. Unter **Project configuration → Identity** Netlify Identity aktivieren.
3. Registrierung auf **Invite only** stellen.
4. Unter **Identity → Services → Git Gateway** Git Gateway aktivieren.
5. Redakteurinnen und Redakteure per E-Mail einladen.
6. Neu deployen und `/admin/` testen.
